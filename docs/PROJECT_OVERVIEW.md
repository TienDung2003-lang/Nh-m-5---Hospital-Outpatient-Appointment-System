# Project overview

HOAS (Hospital Outpatient Appointment System) is a university requirements-engineering case study about outpatient appointment booking and administration. Proposed roles include Patient, Receptionist, Doctor, Administrator and Notification Service.

The repository focuses on appointment lifecycle requirements, role access, slot capacity, booking/rescheduling, check-in, status updates, notifications and traceability. All people, dates and policies in the dataset are synthetic educational examples.

This repository contains a Python in-memory prototype for demonstrating selected business rules; it is not a production or clinical application.
